# Changelog Archives / 更新日志归档

- Public API: `changelogs/;api/v<major>/<major>.<minor>.md`

- 主模组与内置后端：`changelogs/v<主版本>/<主版本>.<次版本>.md`
- 公共 API：`changelogs/;api/v<主版本>/<主版本>.<次版本>.md`

For recent changes and unreleased updates, see [CHANGELOG.md](../CHANGELOG.md) and [CHANGELOG.API.md](../CHANGELOG.API.md).
<br> 有关近期变更及尚未发布的更新，请参阅 [CHANGELOG.md](../CHANGELOG.md) 与 [CHANGELOG.API.md](../CHANGELOG.API.md)。
