# BaruSikoZako 实服验收矩阵

各项按独立证据记录。小地图的 PASS 只覆盖该规模；发布验收仍要求大地图、真实在线与完整故障矩阵。预览的 BUILD / LOAD 仅记录预览 JAR。

本轮已记录 27 个组合的小地图往返、8 个组合的大地图往返和 9 个在线备份验证。
